# 电子校友卡静态页面

直接双击 `index.html`，用浏览器打开即可。无需安装软件、构建项目或配置后台。

请保留以下目录结构；移动页面时，应一起移动整个文件夹：

```text
index.html
assets/
  reference.jpg
  portrait.jpg
```

## 页面功能

- 参考原图还原蓝色顶部、标题、校友卡及刷新按钮。
- 卡片从原始截图中以页面样式裁切展示，保留原有文字和纹理；照片单独使用 `assets/portrait.jpg` 覆盖展示。
- 顶部显示实时北京时间（Asia/Shanghai），格式为 `YYYY-MM-DD HH:mm:ss`，每秒自动更新。
- 时间来自使用者设备的系统时钟，不是截图中固定的日期，也不依赖网络。
- 切回浏览器或从后台恢复页面时，立即校准显示时间。
- “刷新”会立即更新当前时间；独立打开时，“返回”会提示已在首页。
- 适配手机屏幕，桌面浏览器中居中展示。

## 注意

这是仅用于界面展示的静态页面，并未连接学校系统，不能验证校友身份、卡片有效期或作为官方认证凭证。

图片中包含个人信息。请仅在有权使用该图片的范围内使用；未经授权，不要将页面或图片公开发布。

照片可通过替换 `assets/portrait.jpg` 更换；卡片文字信息属于原图内容，不能直接通过修改文字来更换。
